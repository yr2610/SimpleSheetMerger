# SimpleSheetMerger

SimpleSheetMerger は、Excel-DNA で作られた Excel アドインです。現在アクティブなブックをベースブックとして、複数の Excel ファイルの差分を集めてシート単位でマージします。

この説明は、現時点のソースコードの挙動をもとに整理したものです。

## できること

- Excel のリボンに `SimpleSheetMerger` タブを追加します。
- ベースブックに対して、複数の Excel ファイルを選んで差分を取り込みます。
- 変更があったシートだけを選んでマージできます。
- 競合が 1 件だけ、または同じ値に収束している場合は自動反映します。
- 複数の値が競合したセルは一覧画面で解決できます。

## 前提条件

### 実行環境

- Windows 版 Microsoft Excel
- .NET Framework 4.8.1
- Excel-DNA ベースのアドインを読み込める環境

### 利用権限

このアドインは、コード上では**未許可ユーザーを既定で拒否**する作りです。

- `AuthorizationHelper.ALLOW_ALL_USERS` は既定で `false`
- `AllowedUsers` も初期状態では空

そのため、**このままビルドしただけでは誰も使えません**。使い始めるには次のどちらかが必要です。

1. `AllowedUsers` に `DOMAIN\\UserName` 形式のユーザーを追加する
2. 一時的に `ALLOW_ALL_USERS = true` に変更する

未許可ユーザーが操作すると、認可エラーのダイアログが表示されます。

## ベースブック側の準備

アドインは、現在アクティブなブックをベースブックとして扱います。さらに、どのシートのどの範囲を比較するかをベースブックから読み取ります。

### 必須のカスタムプロパティ

ベースブックには、ドキュメントのカスタムプロパティ `IndexSheetName` が必要です。この値に、マージ設定を記述したインデックスシート名を入れます。

### インデックスシートの読み取りルール

インデックスシートでは、以下の列・セル位置が固定で使われます。

- シート名の開始位置: `B16`
- 終端マーカー: `END`
- 左端列: `U`
- 右端列: `AA`
- ヘッダー行: `AD`
- 最下行: `AE`

動作イメージは次の通りです。

1. `B16` から下方向に読み進める
2. セル値が `END` になる直前までを対象にする
3. 各行のシート名ごとに、比較対象範囲を決める

比較対象範囲は、通常は以下で決まります。

- 左端列 = 同じ行の `U` 列
- 右端列 = 同じ行の `AA` 列
- 先頭データ行 = `AD` 列の値 + 1
- 最終データ行 = `AE` 列の値

つまり、各シートのマージ範囲は `左端列 + (ヘッダー行+1) : 右端列 + 最終データ行` で組み立てられます。

### 無視されるシート

インデックスシート上に `無視シート` という名前が書かれている行はスキップされます。

### 名前付き範囲 `SS_SHEET` を使う方法

対象シート側に名前付き範囲 `SS_SHEET` がある場合は、インデックスシートの列設定よりもそちらが優先されます。

- `SS_SHEET` の参照先アドレスが、そのシートの比較範囲として使われます。
- `SS_SHEET` のコメントがあれば、YAML として読み取られます。

YAML コメントでは、次の情報を指定できます。

```yaml
idColumnOffset: 0
ignoreColumnOffsets:
  - 2
  - 5
```

- `idColumnOffset`: マージ時の ID 列オフセット
- `ignoreColumnOffsets`: ID ベースの上書き時に無視する列オフセット

## ID ベースで行を合わせる仕組み

ベースブックとマージ対象ブックの両方で `SS_SHEET` コメント内の `idColumnOffset` が設定されている場合、単純な行番号比較ではなく、ID 値を使って行を突き合わせます。

この場合の挙動は次の通りです。

- ベース側の ID 列を基準に行の並びを決める
- マージ対象ブックの同一 ID 行の値を、ベース側の対応行へコピーする
- `ignoreColumnOffsets` に含まれる列は上書きしない
- ベース側に存在しない ID の行は取り込まれない

## 実際の使い方

### 1. ベースブックを開く

Excel で、マージ先にしたいブックを開いてアクティブにします。

- このブックが最終的に更新されます。
- アクティブなブックがないと処理は開始できません。

### 2. アドインのリボンから `ファイル選択` を押す

リボンには次の 2 ボタンがあります。

- `ファイル選択`
- `Merge`

まず `ファイル選択` を押して、マージ元ファイルを追加します。

### 3. マージ元ファイルを追加する

ファイル選択画面では、次の方法でファイルを追加できます。

- `リストに追加` ボタンから Excel ファイルを選ぶ
- リストへドラッグ & ドロップする

選択できる拡張子は以下です。

- `.xls`
- `.xlsx`
- `.xlsm`

補足:

- ベースブック自身は追加できません。
- すでに追加済みのファイルは重複追加されません。
- `リストから削除` ボタンまたは Delete キーで一覧から外せます。
- `閉じる` または Esc キーで画面を閉じられます。

### 4. `Merge` を押す

`Merge` を押すと、追加した各ファイルを順番に開いて差分を収集します。

このとき、まず以下のような前処理が入ります。

- 画面更新を停止
- 自動計算を手動へ変更
- Excel イベントを停止

差分収集が終わると、変更のあったシート一覧が表示されます。

### 5. マージするシートを選ぶ

シート選択画面では、変更が見つかったシートだけが一覧表示されます。

- 初期状態ではすべて選択済みです。
- `全選択/全解除` ボタンで切り替えできます。
- 行をダブルクリックすると、そのシートを Excel 側でアクティブにできます。
- 何も選ばずに OK しなければ、キャンセル扱いになります。

### 6. 自動反映されるケースを確認する

選択したシートについて、各セルは次のルールで処理されます。

1. 変更元が 1 ファイルだけなら、その値を採用
2. 複数ファイルから同じ値が来ているなら、その値を採用
3. マージ関数が設定されていればその結果を採用
4. それ以外は競合として保留

現状のコードでは、通常の範囲定義からはセル単位のカスタムマージ関数は設定されていないため、実質的には 1 / 2 / 4 の流れになります。

### 7. 競合を解決する

競合がある場合は、競合解決ウィンドウが表示されます。

一覧には以下が表示されます。

- `Resolved`: 解決済みチェック
- `Sheet Name`: シート名
- `Add`: セルアドレス
- `Merged`: 最終採用値
- `Merge`: マージ方法
- `Base`: ベースブックの元の値
- `File 1`, `File 2`, ...: 各マージ元ファイルの値

操作方法:

- 値セル (`File 1` など) をクリックすると、その値を `Merged` にコピー
- 行をクリックすると、該当セル位置へ Excel 画面をスクロールして選択
- `Resolved` をチェックすると解決済み扱い
- すべての行が解決済みになると OK ボタンが有効化

#### `Merge` 列で選べる競合解決方法

- `Concatenate`
  - 空欄を除外
  - 重複を除外
  - 改行区切りで連結
- `AddDifferences`
  - 数値として解釈できる場合だけ有効
  - `sum(各値) + base × (1 - 件数)` で計算
  - 実質的には「各ファイルが base からどれだけ増減したか」を合算する動き
- `CommaSeparated`
  - まだ未実装で、`※マージ処理未実装※` が入ります

競合解決画面で `Merged` を直接編集すると、その場で Excel シート側のセル値にも反映されます。

### 8. 結果を確認して保存する

競合解決後、または競合がなかった場合は、変更があったシート数を示す結果ウィンドウが表示されます。

- 例: `売上: 12`
- これは「そのシートで変更対象になったセル数」を表します。
- 結果一覧をダブルクリックすると該当シートへ移動できます。

コード上では、マージ後に自動保存はされません。必要なら Excel で保存してください。

## 使うときの注意点

- ベースブックの構造が前提に合っていないと正しく動きません。
- マージ元ブックに対象シートがない場合、そのシートはそのファイルについては無視されます。
- 比較範囲のサイズが想定とズレていると、実行時エラーになる可能性があります。
- `CommaSeparated` は UI 上にありますが未実装です。
- 認可設定を変えない限り、初期状態では誰も利用できません。

## 最短の運用手順

1. 許可ユーザー設定を行う
2. ベースブックに `IndexSheetName` を設定する
3. インデックスシートに対象シート一覧と範囲定義を書く
4. 必要なら各対象シートに `SS_SHEET` 名前付き範囲と YAML コメントを設定する
5. Excel でベースブックを開く
6. `ファイル選択` でマージ元ブックを追加する
7. `Merge` を実行する
8. シート選択と競合解決を行う
9. 内容を確認してブックを保存する
